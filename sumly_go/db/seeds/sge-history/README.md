# 上金所 Au99.99 历史日线补录

核对日期：2026-09-30。数据单位为人民币元/克，使用真实交易日的收盘价，
不使用国际金价换算，不做年度平均，不填充周末、休市或缺失日期。

## 数据与核对范围

- 官方历史目录：<https://www.sge.com.cn/sjzx/mrhqsj>，共 386 页、3,851 条档案。
- 官方当前走势图：`POST https://www.sge.com.cn/graph/Dailyhq`，`instid=Au99.99`。
- 保留 3,794 个经过校验、按交易日去重的日线，覆盖 2002-10-31 至 2023-12-29。
- 与当前走势图重叠的 1,697 个收盘价一致，没有收盘价冲突。
- 每条 CSV 保留官方详情页 URL 和抓取 HTML 的 SHA-256，整份 CSV 校验值见 `audit.json`。
- 用正文交易日期和交易时段说明核对发布日期；日期校正清单见 `audit.json`。
  2016-04-12 页面使用英文表头，按 Open / High / Low / Close 对应。
- 校验正数、有限数、开收盘在最高最低范围内；检查重复的完整行情行
  （包含成交量、成交额、涨跌等），将无法确认的重复或矛盾记录保守排除。
  56 条排除记录及原因见 `excluded.csv`，不会删除数据库中已有的对应记录。
- 对相邻收盘价超过 10% 的变化做异常扫描。唯一触发记录跨越了
  2003-04-15 至 2008-08-11 的多年缺口，不能解释成单日涨幅；其余没有触发该阈值。

历史**并不完整**：2003-04-16 至 2008-08-10 之间的日线在该公开目录中缺失，
2009 年末至 2010 年初部分页面复制了同一张完整行情表，不能作为有效价格入库。
另有零星空白表、开高低收矛盾和日期矛盾。缺口保留，不插值，不用前值填充。
2008–2016 年曾用公开休市安排辅助核对工作日；这只是缺失检查，不能据此推算价格。
用户已确认接受稀疏历史，所有能核实的数据均可补录。

## 导入

只向 `gold_daily_bars` 插入缺少的 `AU9999` 日期，已有记录保持原样。
现有 `market_daily_projection` 触发器同步写入 `market_history_points` 并递增历史版本，
App 可以沿用已有 cursor 获取新增历史，无需重新上传 App。
本地同步有 15 分钟检查间隔；想立即查看可使用“我的 → 清除缓存”后回到首页。
操作不需要重启后端，也不改变历史版本的 epoch。

先比对 `audit.json` 中的 SHA-256，再在本目录运行（连接配置通过安全环境提供）：

```sh
sha256sum sge-au9999.csv
psql -X -v ON_ERROR_STOP=1 -f import.sql
psql -X -v ON_ERROR_STOP=1 -v apply=1 -f import.sql
```

第一个命令只检查文件，第二个事务默认回滚；第三个才提交。
显式 `apply=0` 也会回滚。连接的 `search_path` 必须指向 Sumly schema。
脚本检查数据数量、日期边界、价格范围、旧记录不变及历史投影一致性；失败整体回滚。
重复导入应插入 0 条，并保持历史版本不变。
